# Changelog

## v0.1.0

- Spec-generated Postgres entities, typed record APIs and local forms.
- Reviewed migration plans, explicit rename hints, default archives and plan hashes.
- Workflow graph transitions, roles, ownership, justification and daily limits.
- Access-request and equipment-checkout examples with neutral/synthetic data.
- Reports/exports and optional local OpenAI-compatible designer with repair loop.
- Bundled JavaScript/fonts, Docker Compose packaging and CI.
- Prompt-first designer with bring-your-own OpenAI key (browser-only, fixed endpoint).
- "Continue as guest" (`GUEST_LOGIN`) and optional guest designer (`GUEST_DESIGNER`).
- Light theme first, dark behind a persisted toggle.

Real-model quality with 7-8B local models is not yet verified.
